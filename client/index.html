Help

Getting Started
Joining Choose White, Black, or Spectate from the join screen. White/Black seats fill first-come-first-served; Spectate is always available.
Your role Role badge (top-left on desktop, top bar on mobile) shows White/Black/Spectator.
Menu button ☰ button (top-left on mobile top bar, top-right on desktop) opens the main menu. On desktop, clicking the role badge also opens the menu.
Turn indicator Center-top shows whose turn it is with a colored dot matching the active player.
Playing
Piece mode (default) Click a piece to select, click a highlighted square to move. Green dot = valid move, ring = capture.
Camera mode TAB or ♟ button switches to camera mode. WASD to move, mouse to look around. Click "Piece Mode" label to switch back.
2D board ⬜ button toggles a 2D board overlay. Click pieces to move. Desktop: small board in top-right, click again for fullscreen. Mobile: centered overlay.
Pawn promotion When a pawn reaches the back rank, pick Queen, Rook, Bishop, or Knight.
Annotations
Draw arrows Right-click and drag between two squares to draw an arrow. Arrows appear on both the 2D and 3D boards. Knight-move arrows bend in an L-shape.
Highlight squares Right-click a square (no drag) to highlight it. Same colors as arrows. Multiple highlights on the same square replace each other.
Annotation colors Hold a modifier while releasing: Ctrl = red, Alt = blue, Shift = green. No modifier = yellow.
Clear annotations Left-click anywhere on the board to clear all arrows and highlights.
Desktop only Annotations require a mouse with a right button.
Camera & Controls
Camera positions Numbered buttons (1–6) at bottom save/restore camera angles.
Virtual joystick Toggle in menu. Left joystick orbits camera, right slider adjusts zoom. Enabled by default on touch devices.
Mouse sensitivity Slider in menu adjusts camera speed (1–100, logarithmic scale). Default is 20.
Fullscreen ⛶ button toggles browser fullscreen. Hidden on browsers that don't support it.
Game Actions
New Game "New Game" in menu resets the board. Only available to active players.
Offer Draw "Offer Draw" in menu sends a draw request. Opponent accepts or declines.
Claim Draw "Claim Draw" button appears when a 50-move-rule or threefold-repetition draw is eligible. The 75-move rule is automatic.
Concede "Concede Game" in menu ends the game with a loss. Confirmed via popup.
Give Up Spot "Give Up Spot" in menu frees your seat. Confirmed via popup.
Info Panels
Move log Scrollable list of moves in algebraic notation. Desktop: bottom-right, full history. Mobile: status drawer, last 6 move-pairs.
Captured pieces Unicode symbols of pieces each side has captured, sorted by value (Queen > Rook > Bishop > Knight > Pawn).
Draw info Shows 50-move counter, 3-fold repetition count, and 75-move auto-draw progress. Appears when any counter is active.
Status drawer (mobile) ℹ button opens a slide-down panel with player count, captures, moves, and draw info.
Settings & Export
Sound 🔊 button toggles sound on/off. State persists between sessions.
Computer opponent Select skill level (Beginner → Grandmaster) and start a game vs Stockfish AI.
Export FEN/PGN Copies the current position (FEN) or full game (PGN) to clipboard.
Import FEN Paste a FEN string to load any position. Requires player role.
Notifications
Toasts Brief messages at the bottom: green (info), red (error), yellow (warning). Auto-dismiss after a few seconds.
Opponent disconnected Orange banner appears when your opponent disconnects. "Drop Player" button available after a countdown.
Game available Green banner for spectators when both players disconnect — click to join.
Reconnecting Full-screen overlay with spinner when connection is lost. "Give Up" button to abort.
Keyboard Shortcuts
TAB Toggle between Piece mode and Camera mode.
ESC Open/close main menu.
